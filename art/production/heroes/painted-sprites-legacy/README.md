# Malowani bohaterowie (wersja sprzed modeli 3D)

Arkusze animacji czterech ras używane w grze do 17.11.2026, przeniesione tu (poza projekt Godot, więc nie trafiają do APK), gdy właściciel zastąpił je bohaterami renderowanymi z modeli 3D. `actors-painted.json` to ich dawne definicje (`<świat>.hero`, ścieżki wskazują ten folder). Przywrócenie: przenieść pliki do `ports/godot-pyra/assets/actors/`, zamienić ścieżki z powrotem na `res://assets/actors/` i wstawić wpisy do `data/actors.json`.
